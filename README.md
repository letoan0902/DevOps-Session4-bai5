# DevOps Session 04 - Bài 5: Khôi phục trạng thái và đảo ngược commit (Reset vs Revert)

Bài tập thực hành Git: dùng `git reset --mixed` để lùi lịch sử cục bộ (giữ thay đổi ở Working Directory) và `git revert` để đảo ngược an toàn một commit cũ bằng commit mới. Báo cáo kèm output thật chạy trên Git Bash (Windows 11, git 2.49.0.windows.1).

Báo cáo chi tiết: [homework/session_04/ex5/README.md](homework/session_04/ex5/README.md)

## Danh sách file

- `README.md`: tệp này.
- `homework/session_04/ex5/README.md`: báo cáo chi tiết hai trường hợp, so sánh reset/revert, làm việc cá nhân và làm việc nhóm.
- `homework/session_04/ex5/terminal_log.txt`: toàn bộ lệnh và output thật.
- `homework/session_04/ex5/calculator.py`: bản cuối của file mã nguồn trong repo thử nghiệm.
